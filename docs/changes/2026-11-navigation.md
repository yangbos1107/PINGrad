# 首页与选校导航调整

本记录描述本地预览阶段。后续 Docusaurus 升级、界面双语与用户授权 push 的交付更新见 [界面升级记录](2026-11-interface-i18n.md)。

## 目标与约束

GOAL-001：让 PIN 同学从首页快速找到项目和申请案例，使用中性的导航方式。

- CON-001：沿用 Docusaurus、现有字体和青绿色；不新增依赖，不改写学校经验。
- CON-002：仅本地修改和预览，不提交、不 push、不部署。
- ASM-001：默认按地区与校名排序，取消公开 Zone 分级；保留历史链接兼容。
- OOS-001：本轮不调整 DataPoints 数据、提交接口或其他占位功能。

| 需求 / 验收 | 实现与可观察结果 | 验证 |
| --- | --- | --- |
| REQ-001 / AC-001 | 首页首屏可见地区、录取案例和分享入口，保留朴素风格 | TC-001 桌面及窄屏实看 |
| REQ-002 / AC-002 | 地区页直接展示全部项目，同校项目合并，支持名称和简称搜索及空结果恢复 | TC-002 搜索、清空、链接和完整性检查 |
| REQ-003 / AC-003 | 导航、页脚、介绍不再提供申请跟踪；两个历史入口返回首页 | TC-003 历史路径与文案检查 |
| REQ-004 / AC-004 | 侧栏和地区索引不展示难度等级；旧 Zone 目录跳转地区页，学校链接保持有效 | TC-004 排序、侧栏与历史路径检查 |
| REQ-005 / AC-005 | 生产构建、类型检查通过；只提供本地预览 | TC-005 构建与类型检查 |

## 方案与接口

ADR-001：比较保留 Zone 并增加解释、改为地区与校名索引两种方案。选择后者，减少高低等级暗示和额外导航层级。目录不推断录取概率，申请者仍可阅读原有项目经验。历史 URL 中的 Zone 暂时保留，避免迁移学校内容。

- MOD-001：`src/lib/programs.ts` 定义地区、排序、分组和名称匹配；供侧栏与页面共用。
- MOD-002：`plugins/programCatalog.ts` 从 Docusaurus 已解析的文档元数据生成项目目录，不维护第二份学校清单。
- MOD-003：`src/components/ProgramDirectory` 渲染地区列表和本地搜索；首页直接链接地区文档。
- IF-001 / IN-001：文档的 `id`、`title`、`sidebar_label`、`permalink`；搜索为任意 Unicode 字符串，默认空串。
- IF-001 / OUT-001：只展示对应地区的学校及项目链接，按校名排序（英文忽略开头 The，中文按拼音）；空串显示全部，无匹配显示恢复按钮。无网络写入。
- MOD-004：历史入口通过客户端跳转兼容，并提供静态返回链接；兼容页不进入搜索索引。
